# Carlos Lopez - Game Designer Portfolio

Static portfolio prototype built with semantic HTML, CSS and vanilla JavaScript.

## Routes

- `index.html` - portfolio index
- `projects/project-1/` through `projects/project-4/` - reusable project archives
- `narrative/narrative-design/` - narrative design territory
- `narrative/stories/` - literary archive

The site has no build step or external runtime dependency and can be opened directly from `index.html` or served by any static file server.
