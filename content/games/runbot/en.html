Overview

Runbot was a runner game built around fast, reflex-driven play. My work focused on upgrading an existing game by analysing the features and gameplay loops that needed to change, then carrying those changes through implementation, balance and presentation.

My Contribution

Gameplay & Feature Upgrades

I analysed the existing feature set and gameplay loops to identify what needed to be upgraded, then implemented the new features designed for the revised experience. The work combined design decisions with hands-on development inside the existing Unity project.

Balance & Technical Integration

Introducing new gameplay features required the rest of the game to be rebalanced around them. I adjusted the overall balance so the new mechanics fitted the existing experience, and I also worked directly with shader code when technical fixes were needed.

FX & UI Polish

I created new FX and UI animations to improve the presentation of the upgraded game. These tasks were part of the final polish pass, supporting the new gameplay changes with clearer and more responsive visual feedback.
